# Daniel Philips — Developer Portfolio

A responsive, single-page developer portfolio built with semantic HTML, CSS, and vanilla JavaScript. It has no build step or external JavaScript dependencies, so it can be edited and deployed as a static site.

## Preview locally

1. Extract the ZIP (or open this folder in VS Code).
2. Open `index.html` in a browser. For the best local development experience, use the VS Code **Live Server** extension.
3. Edit `index.html` for content, `styles.css` for the visual design, and `script.js` for interaction.

## Deploy

### Vercel
1. Create a new GitHub repository and upload the contents of this folder.
2. In Vercel, select **Add New → Project** and import the repository.
3. Choose **Other** as the framework preset if asked. Leave build command and output directory empty/default for a static site.
4. Deploy. The site uses relative asset paths, so the portrait and favicon will deploy with it.

### Netlify
Drag the extracted folder into Netlify's manual deploy area, or connect its GitHub repository. No build command is required.

### GitHub Pages
Push the contents to a GitHub repository, then enable Pages from the repository's Settings. Choose the branch and root folder.
